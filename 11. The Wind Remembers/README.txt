THE WIND REMEMBERS
Linux x86_64 REV challenge

Run from this directory:
    ./game.x86_64

Controls:
    WASD       Move
    Mouse      Look
    F          Toggle torch
    I          Inventory
    E          Interact / inspect
    J          Read recovered fragments
    Escape     Release or capture mouse; close menus

Keep game.x86_64, game.pck, and libtrial.so together.
The game uses Godot 4.7.2's Compatibility renderer.
