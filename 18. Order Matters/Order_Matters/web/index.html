Order Matters

Fifteen exhibits. Nine selections. The order matters.

Start with the intake record. After that, use the observation inside the box you just opened and the separately provided PCAP to choose the next box. You need nine boxes in the right order. Every new selection is permanent: one wrong choice silently poisons the whole run, so the fragments will not decrypt. There is no undo, and the site will not tell you when you have made a mistake. Reopening a box you already selected is safe; it shows the same saved entry and does not count as another selection.
