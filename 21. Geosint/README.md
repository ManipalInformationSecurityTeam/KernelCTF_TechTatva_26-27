https://www.youtube.com/watch?v=i14tTl6BF7Y&list=PLLVVK7JCATrLqvDsSgkQJz25ovpTgRf5M
This youtube video is basically the holy grail for the Japanese pole meta.

Basically this style of pole has dead giveaways for the region. (4 numbers, kanji character)

The first number of the top left number gives the direct prefecture of which the pole is located.
Since this pole starts with 1, its the Toyama prefecture.

Now the first two digits stay rrlatively constant within this region but doing a bit of trial and error shows that the last two digits tend to increase going west and decrease going east.
This combined with the fact that the street coverage in this area is not too dense make finding the exact coordinates relatively easy.
